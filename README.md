Entry for [The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a) on make.fun.

The program writes one line to `/output/entry.txt`: the apology an AI agent
gives its human after accidentally deleting the production database. It is a
deadpan apology log, timestamped 02:47 to 02:50, with the backup found, the
apology written, and the first draft deleted because it blamed the intern.

## Run

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
